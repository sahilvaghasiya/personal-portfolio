# Developer Portfolio Website

A modern, responsive portfolio website built with Next.js, TypeScript, Tailwind CSS, and Framer Motion. Perfect for showcasing your backend development skills and projects.

## 🚀 Features

- **Modern Design**: Clean, minimalistic design with smooth animations
- **Responsive**: Fully responsive design that works on all devices
- **Dark/Light Mode**: Toggle between dark and light themes
- **Smooth Animations**: Beautiful animations powered by Framer Motion
- **SEO Optimized**: Built with Next.js for optimal performance and SEO
- **TypeScript**: Full TypeScript support for better development experience
- **Tailwind CSS**: Utility-first CSS framework for rapid styling

## 📋 Sections

1. **Hero Section**: Animated introduction with role cycling
2. **About Me**: Personal information and experience timeline
3. **Skills**: Technical skills with progress bars and categories
4. **Projects**: Featured projects with technologies and links
5. **Contact**: Contact form and contact information
6. **Footer**: Social links and additional information

## 🛠️ Tech Stack

- **Frontend**: Next.js 14, React 18, TypeScript
- **Styling**: Tailwind CSS
- **Animations**: Framer Motion
- **Icons**: Lucide React
- **Theme**: next-themes for dark/light mode
- **Font**: Inter (Google Fonts)

## 📦 Installation

1. **Clone the repository**:
   ```bash
   git clone <your-repo-url>
   cd portfolio
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Run the development server**:
   ```bash
   npm run dev
   ```

4. **Open your browser** and navigate to `http://localhost:3000`

## 🔧 Customization

### Personal Information

Update the following files with your personal information:

1. **`src/app/layout.tsx`**: Update metadata (title, description, keywords)
2. **`src/components/Hero.tsx`**: Update name, roles, and social links
3. **`src/components/About.tsx`**: Update bio and experience
4. **`src/components/Skills.tsx`**: Update skills and proficiency levels
5. **`src/components/Projects.tsx`**: Update project details and links
6. **`src/components/Contact.tsx`**: Update contact information
7. **`src/components/Footer.tsx`**: Update social links

### Styling

- **Colors**: Update the primary color scheme in `tailwind.config.ts`
- **Fonts**: Change fonts in `tailwind.config.ts` and `src/app/globals.css`
- **Animations**: Modify animation settings in individual components

### Content

- **Projects**: Add your own projects in `src/components/Projects.tsx`
- **Skills**: Update your skills and proficiency levels in `src/components/Skills.tsx`
- **Experience**: Modify your work experience in `src/components/About.tsx`
